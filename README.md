## Sobre o repositório

Este repositório reúne o conteúdo produzido e consultado ao longo da disciplina. A trilha acompanha os temas desde os fundamentos de DevOps e o ciclo de entrega até pipelines, testes automatizados e documentação de software.

Cada registro de aula apresenta o tema estudado e organiza as **atividades propostas e realizadas**. Quando aplicável, também identifica o projeto utilizado, os resultados documentados e os materiais de referência. Proposta e execução são descritas separadamente para que fique claro o que foi solicitado e o que foi efetivamente registrado.
