## Sobre o repositório

Este repositório reúne o conteúdo produzido e consultado ao longo da disciplina. A trilha acompanha os temas desde os fundamentos de DevOps e o ciclo de entrega até pipelines, testes automatizados e qualidade de software.

Os registros descrevem os assuntos e atividades documentados em cada aula. Os PDFs complementam as anotações com o material disponibilizado para estudo.
